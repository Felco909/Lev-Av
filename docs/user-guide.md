# Руководство пользователя — LevAV TMS

## Разделы системы

| Раздел | Для кого | Что показывает |
|---|---|---|
| **Главная (Dashboard)** | Все | KPI дня/месяца, риски, рейтинги клиентов/машин, карта, финансовый график |
| **Лист дня** | Логист, Бухгалтер, Директор | Конкретные задачи на сегодня по трём ролям, с быстрыми действиями на каждой карточке |
| **Заявки** | Логист | Список сделок, создание/редактирование, статусы |
| **Календарь** | Логист | Загрузки/разгрузки по датам |
| **Долги** | Бухгалтер, Директор | Кто должен нам, кому должны мы, кассовые разрывы, просрочки |
| **Отчёты** | Директор, Бухгалтер | Прибыль/убытки, свой автопарк, долги, экспорт Excel/PDF |
| **Аналитика** (машины/водители/клиенты/маршруты) | Директор | Рейтинги и показатели за период |
| **Машины / Водители / Перевозчики / Клиенты** | Все | Справочники |
| **Рейсы машин** | Логист | Собственные рейсы (выезд/возврат, привязанные заявки) |
| **Топливо** | Логист/Механик | Ручной журнал заправок (для сверки; расход считается автоматически по Wialon) |
| **Техобслуживание** | Механик | Регламенты и записи ТО |
| **Телематика** | Логист | GPS-статус машин, онлайн-карта |
| **Документы** | Бухгалтер | Загруженные файлы, шаблоны |

## Создание заявки

1. «Заявки» → «Новая заявка».
2. Выбрать клиента, заполнить маршрут и дату.
3. Выбрать тип: «Собственные машины» (обязательно указать машину и водителя) или «Экспедиция» (указать перевозчика и его ставку).
4. Указать ставку клиента.
5. При необходимости — доп. расходы (кнопка «Добавить»): указать, чья это сторона (клиентский расход увеличивает то, что должен клиент; расход перевозчика увеличивает то, что причитается перевозчику).
6. Сохранить.

## Проведение заявки по статусам

Кнопки смены статуса — на карточке заявки. Каждый шаг — только на соседний статус (нельзя перескочить сразу в «Завершён»). Порядок: Новая → В пути → Разгружен (нужна дата разгрузки) → На оплату (срок оплаты посчитается автоматически, если у клиента задан срок в днях) → Сверка → Завершён.

**Завершить заявку можно только если:** клиент оплатил полностью (с учётом доп. расходов), перевозчик (если экспедиция) получил оплату полностью, указан налоговый код. Если система не даёт завершить — она покажет точную причину и сумму остатка.

## Внесение оплаты

На карточке заявки — кнопка «Добавить оплату» (клиента или перевозчика). Указать сумму, валюту, дату. Система сама не даст создать точную копию платежа при случайном повторном нажатии в течение нескольких секунд.

## «Лист дня» — как читать

Три независимые колонки: Логист (что нужно сделать по машинам/рейсам), Бухгалтер (документы/оплаты), Директор (компактная финансовая сводка + «Требует внимания»). Каждую категорию можно свернуть/развернуть, любую колонку — открыть на всю ширину (кнопки в её заголовке). Фильтры сверху (Сегодня/Завтра/Неделя/Все, приоритет, статус) применяются сразу. Карточка задачи содержит быстрые действия: «Открыть», позвонить клиенту/водителю (если указан телефон), изменить статус, отметить готовым (скрывает карточку до следующего обновления, не меняя саму заявку).

## Цветовая индикация приоритета

🟢 Норма · 🟡 Требует внимания · 🟠 Срочно · 🔴 Просрочено — единая система на «Листе дня», «Долгах» и Dashboard.

## Экспорт

Excel и PDF — кнопки в шапке Dashboard и «Отчётов». PDF формируется через локальный конвертер, может занимать 10-15 секунд — это нормально, не нажимайте повторно.

## Частые вопросы

**Заявка не отображается в доходе собственного транспорта** — проверьте, привязана ли она к рейсу (раздел «Рейсы машин»). Без привязки заявка находится в статусе «Ожидает привязки» и не входит в доход, пока привязка не будет сделана явно.

**Цифры на разных экранах не совпадают** — если фильтры по датам разные, это ожидаемо (например, Dashboard за месяц и «Долги» без ограничения периода — разные вопросы). При одинаковых фильтрах все разделы показывают одинаковые числа.

**Не получается закрыть заявку** — система покажет точную причину (какая сторона и сколько ещё должна, или не указан налоговый код).
