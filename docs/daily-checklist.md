# Чек-лист ежедневной проверки системы — LevAV TMS

Занимает 3-5 минут. Рекомендуется проверять после 13:20 (когда все ночные/дневные задачи уже отработали).

## 1. Сервер жив
- [ ] Сайт открывается: http://192.168.0.100:3000
- [ ] `HEALTH_CHECK.bat --no-pause` → `[RESULT] READY`

## 2. Бэкапы прошли сами (без ручного вмешательства)
- [ ] `C:\Users\user\LevAv_Postgres_Backups\logs\pg_backup.log` — последняя запись за сегодня: `END backup success`, **без** следующей строки `WARN`
- [ ] `...\logs\attachments_backup.log` — за сегодня: `END backup success`
- [ ] `...\logs\google_drive_backup.log` — за сегодня есть `OK copied to Google Drive` для файла БД и для архива вложений
- [ ] Новый файл появился и локально (`...\db\`, `...\attachments\`), и на `G:\Мой диск\...` — размеры совпадают

## 3. Финансовые данные не разъехались
- [ ] Открыть Dashboard и «Долги» — суммы ДЗ/КЗ/кассового разрыва должны совпадать при одинаковом периоде
- [ ] На «Листе дня» вкладка Директор — кассовый разрыв совпадает с Dashboard

## 4. Wialon/GPS работает
- [ ] На Dashboard — «последняя синхронизация Wialon» показывает свежее время (не «нет данных»)
- [ ] `/telematics` — хотя бы часть машин показывает `moving`/`stopped`, а не сплошной `no_signal`

## 5. Нет накопившихся проблем
- [ ] «Лист дня» → блок «Срочные проблемы» и «Просроченные действия» — при появлении новых пунктов не игнорировать больше 1-2 дней
- [ ] «Долги» → «Требует внимания» — просроченные оплаты/кассовые разрывы не растут неделями без движения

## 6. Раз в неделю — дополнительно
- [ ] `npm test` (из папки проекта) — все тесты зелёные
- [ ] Свободное место на диске C: не критично мало (`Get-PSDrive C`)
- [ ] Планировщик заданий: `Get-ScheduledTask | Where TaskName -like 'LevAV*'` — все `Ready`, ни одной `Disabled`/пропавшей

## Если что-то не так

| Симптом | Куда смотреть |
|---|---|
| Сайт не открывается | `HEALTH_CHECK.bat`, затем `PRODUCTION_START.bat` |
| WARN про диск G: в бэкапах | `Test-Path "G:\"`, `Get-Process GoogleDriveFS` — при необходимости перезапустить Google Drive Desktop вручную |
| Разные цифры на Dashboard/Долгах | Проверить, одинаковый ли период фильтра; если период одинаковый — это баг, требует разбора |
| «Нет данных» синхронизации Wialon | Проверить `logs/company_base_check.log` на систематические (не единичные) ошибки |
| Много новых «Срочных проблем» на Листе дня | Разобрать с логистом/бухгалтером в течение дня, не копить |
